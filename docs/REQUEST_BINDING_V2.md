# Pure request binding v2

Additive SDK module `hopae_grpc::request_binding_v2`; v1 module/source/golden vectors remain unchanged. This is a pure codec, not Human authentication, a receipt, a prepared proof, an active RPC or authorization capability.

`HeaderPolicy::new(revision, names, reserved_names)` compiles sorted server-fixed lowercase RFC tchar names (1..128 bytes). Positive revisions are at most9007199254740991. Empty manifests are allowed, at most16 slots and64 reserved names; duplicates, malformed names, built-in security/framing/hop/identity fields and configured reserved-name collisions refuse before cloning names. The caller must reserve every custom caller/projected-credential/identity header; the pure codec cannot infer them. Unrelated actual headers stay outside the bound-slot DTO.

`digest(&HeaderPolicy, &Request)` accepts actual complete `body: &[u8]`, computes its length/SHA256 internally without copying it, and offers no raw body-digest shortcut. Body cap is exactly16MiB. Request metadata binds service, audience, route ID/revision and nonzero selected-destination SHA, method and exact origin-form target. Destination provenance is a native owner obligation, not established by hashing a supplied value. Identifiers/method/target use v1 validation, with no path/query/percent normalization.

Every configured slot appears exactly once as `BoundHeader { name, value: Option<&[u8]> }`; None and present-empty differ. Descriptor order is irrelevant; the compiled manifest orders encoding. Unknown, duplicate or missing slots refuse. Values preserve exact bytes including obs-text; CTL including TAB and DEL refuse, each value<=1024, aggregate<=8192. Request/BoundHeader Debug redact all descriptor content. Configuration/header selection remains the trusted owner's responsibility; this pure data is never a native grant.

Normative encoding and independent Python reference: public ZT commit `98874bc`, `docs/reviews/2026-10-16-request-binding-v2.md`, `tools/request_binding_v2_reference.py`. Exact synthetic fixture copied from `fixtures/request-binding-v2.json`, SHA256 `2965d4c2eaeaed39a866758aa13d9c7a9d43393908c3507dc90ee175c68a1352`. Rust consumes all seven independent expected SHAs, not self-generated expected digests. Domainv2NUL; LP32 service/audience/route ID; BEu64 route revision; raw32 destination; LP32 method/target; BEu64 actual body length/raw32 computed SHA; BEu64 policy revision; BEu16 count; sorted slots LP32 name/presenceu8/if-present LP32 value.

Tests cover actual empty/nonempty/same-length body mutation, route/destination/method/query/base-path changes, slot order/absence/empty/exact values, forbidden/reserved/duplicate/unknown inputs, control bytes and bounds. These are source codec results, not Human wire/product, runtime owner or fullchain qualification. No proto, existing receipt validator, Service/Workload semantics, native clocks or runtime activation changed.
