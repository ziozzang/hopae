# Native Human paired projection foundation

This candidate is the private native-current and Store writer foundation for H4. It does not mount a Human projection RPC or qualify a Human credential chain.

`SnapshotCheck` preserves the existing joined handle/session/user/provider/realm, primary material, TOTP provenance, lifetime and step-up comparisons. The existing asynchronous native read still prepares the same expected facts and runs the comparison inside its original checked read transaction. Application policy is retained as an exact immutable publication Arc and an opaque O(1) locator, without a deep AppPolicy copy.

Only an actual retained native `Checked` prepares `ProjectionCurrent`. It anchors the system suspend-aware elapsed clock before its native sample. Repeated checks advance that fixed original sample conservatively with ceiling and quantum; they never renew original admission or native expiry. No wall, caller metric, network or owner test-clock callback runs inside the writer. Read failure/reversal, owner/readiness/publication withdrawal or a failed durable comparison irreversibly retires that check and capture.

`Store::human_ledger` queues on the existing native Store writer. It supplies a sealed mutable Ledger whose connection cannot be selected by a request, and whose read-only LedgerSnapshot structurally binds the exact Store to the transaction guard. ProjectionCurrent rejects another Store, even if it has a compatible schema. The bridge delegates to the existing canonical `consume_observed_pair`; it creates no replay table, algorithm or class namespace. There is no nested wrapper transaction. A request cancellation/expiry fence must still be retained by the eventual H4 operation and checked by the shared pair transaction before commit. Cancellation after commit burns the pair; it cannot promise rollback or resend a secret.

H4 orchestration, actual source Arc sharing, typed Pum Human permit observation, explicit default-off scopes, original predecode query intersection, final async native checks and real credential/replay endpoints remain subsequent implementation gates. A local native check is not a fabricated public SDK Observation. H3 must independently verify the actual native source through the public Human SDK, including its authenticated scope fingerprint. One signed final H1v2 digest must remain identical throughout the chain; no digest rebinding is introduced.
